\section*{Tidy summaries}
Every name of a package links to its help page, packages attach where the code loads them, and
operators become \enquote{ligatures} that still copy as the original text:
\begin{minted}{mr}
library(dplyr)
library(ggplot2)

by_cyl <- function(data) {
  data |>
    group_by(cyl) |>
    summarise(mpg = mean(mpg), n = n())
}
ggplot(by_cyl(mtcars), aes(cyl, mpg)) + geom_col()
\end{minted}
Inline, too: \bmr{stats::filter(1:10, rep(1/3, 3))}. R knows the answer: the cars average
\mrValue{round(mean(mtcars$mpg), 1)} miles per gallon. And a session:
\begin{rsession}
x <- c(2, 3, 5, 7, 11)
sum(x[x > 2])
\end{rsession}
\section*{What flowR sees}

draws the dataflow of the listing:

raw <- read.csv("cars.csv")
fast <- subset(raw, speed > 20)
write.csv(fast, "fast.csv")
\end{mr}
